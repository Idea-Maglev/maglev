# 步骤 6：开放世界审查与修订

## 机械观察

运行配置、完整来源全集、挑战隔离与集成收据、差异与剩余风险、独立审批收据、计划与实际页面对应、来源摘要、全部导航链接、漂移和人类可读完整性检查。机械通过不表示内容充分。

## 联合任务集

独立审查 Agent 使用以下任务并集，而不是只读取 Plan：

```text
Plan 页面任务
∪ Blind Challenge 问题
∪ 风险与 unknown 任务
∪ 本次变更影响任务
∪ 独立业务问答
```

每个输入中实际存在的 Plan、Challenge、剩余风险和变更任务都必须生成确定性任务 ID，并记录匹配的来源类型、关联页面、读者实际答案、页面证据、来源证据、结论、发现和修订建议；不能只声明支持 `risk` 或 `change` 类型而不要求对应任务。

## 反证要求

审查必须主动记录：

- 尝试推翻的结论；
- 使用的冲突来源或反例；
- 最可能错误的页面；
- 被排除的遗漏候选及理由；
- 仍因证据不足保持 blocked 的问题。

不要求固定数量的问题；但没有反证轨迹时不得全量通过。仓库执行收据无法认证会话历史或人类身份，充分性保持 `provisional`。

## 自动修订

可安全修复的问题由 Agent 修订并重审，同一页面最多三轮。结构需要变化时返回结构审核；证据不足、审查不可用、摘要不一致或三轮未收敛时阻断。
