# 步骤 1：加载基准与项目输入

1. 加载项目人类可读输出契约；缺失时不得提交结构方案或成品简报。
2. 读取 `.maglev/wiki.yaml`，取得项目标题、语言、来源允许列表和可选受众提示；
3. 检查 Plan、Source Universe、Challenge Receipt、Challenge、Divergence、Markdown 审阅面和已接受 review 基线：
   - 没有 Plan：创建模式；
   - 有完整且摘要一致的批准束：更新模式；
   - 来源策略、Source Universe、Challenge、Divergence、Plan 或人类审阅面任一变化：结构重审模式；
   - Challenge 输入包含 Plan、Divergence 或现有 Wiki：挑战无效，重新进入隔离挑战。
4. 找不到安全事实根时阻断，不扩大读取范围。
5. 没有真实用户问题或独立业务问答时，记录充分性上限为 `provisional`。
