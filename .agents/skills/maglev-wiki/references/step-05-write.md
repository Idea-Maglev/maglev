# 步骤 5：写作或更新正文

- 只写批准结构中的页面；结构需要变化时返回结构审核步骤；
- 以页面的读者任务、用途和证据组织内容；
- 同时消费关联 Challenge concern 和 depth signals；它们提示应深入核对流程、状态、数量、失败、集成、unknown 或决策，不生成固定章节；
- 内容深度由问题复杂度和证据密度决定，不模仿模板示例篇幅；
- 模板方向可以采用、组合或不用，不产生固定章节义务；
- 无证据的事实明确写成未知或阻断，不补常识；
- `deferred`、`blocked` 和未完全覆盖的 concern 必须在正文边界或最终风险中可见，不能因 Plan 已批准而消失；
- 页面 frontmatter 只保存定位、受众、可选写作方向、来源和更新时间；`source_bindings` 必须非空，并与该批准页面的来源集合完全一致；
- 人类可读输出契约从第一稿持续生效。
