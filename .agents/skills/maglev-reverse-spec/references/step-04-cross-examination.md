# 现实资料对抗审查

## 目标

检查既有现实资料、本次变化、代码、测试和已知运行证据是否互相一致。审查对象是完整结果，
不是只看新增页面。

## 在流程中的位置

本文件属于阶段 B 的独立对抗审查。它只审查已经写入目标项目的完整现实资料和候选提交，
不回到阶段 A 生成模块或替代用户边界裁决。

## 审查顺序

1. 检出与生产者相同的候选提交；
2. 读取完整现实资料；
3. 以基线对照本次变化；
4. 逐条核对事实页面中的结论、事实类型、证据引用、未知和假设；
5. 输出可回查的问题项；
6. 需要改动时，由生产者生成新的候选提交后重新审查。

## 审查内容

### 事实支持

- 页面声称的行为是否能在代码、测试或已提交运行证据中找到；
- 没有证据的内容是否被标为推断、未知或阻断；
- 证据引用是否真正支持对应结论。

### 内容遗漏

- 代码中的异常分支、空值防御、重试、回滚、降级、异步补偿是否被遗漏；
- 适用维度是否已经明确状态；
- 未知和阻断是否写出影响和继续求证位置。

### 既有资料与本次变化

- 是否与既有事实冲突、重复或使其失效；
- 是否误删既有事实、业务域入口或证据；
- 变化是否超出本轮范围。

### 跨层一致

- 页面、接口、处理过程和数据结构的字段及含义是否一致；
- 默认值、状态、错误和权限是否出现不一致；
- 依赖方向是否与代码可回查关系一致。

## 输出格式

```markdown
# 现实资料审查问题

## 阻断问题

- [不支持的事实] <问题和证据>
- [遗漏] <问题和证据>

## 非阻断问题

- [定位] <问题和证据>
- [推断边界] <问题和证据>
- [跨层不一致] <问题和证据>

## 结论

- 通过 / 拒绝 / 通过但保留问题
```

只有所有阻断问题已经处理，或被明确交接为阻断状态，才能进入准入判断。
