### [接入、协作与日常操作](developer/README.md)

> 帮助开发者完成首次接入、日常主流程、导航、更新、排障与知识验证。（面向 developer）

**首次成功**：读者需要在目标项目中自行执行或委托 AI Agent 完成首次初始化，确认受管入口，并在需要运行协议脚本时检查运行时。
- [第一次接入并确认成功](developer/first-success.md)：在项目根目录自行执行或委托 AI Agent 完成首装，确认生成的受管入口，并知道何时需要检查运行时后进入后续工作流。 提供从零到可用的两种初始化入口、最短操作路径和可观察成功标准。

**存量接入**：读者需要在不破坏既有代码的前提下，把存量项目逐步纳入 Maglev。
- [存量项目渐进式接入](developer/brownfield-adoption.md)：为已有代码选择接入范围，执行局部逆向和准入，并知道何时不应扩展范围。 将存量项目的诊断、逆向、准入、索引和增量覆盖组织成可执行路径。

**日常协作流程**：读者需要从一个请求进入正确的主流程，并在会话切换和任务收尾时保持状态可追踪。
- [从请求到结晶的日常协作](developer/session-workflow.md)：从请求分诊开始，完成需求、方案、实施、验证与结晶，并在会话切换时重新对齐现状。 提供开发者可执行的主流程、交接点和收尾检查。

**导航与上下文**：读者需要快速定位权威文件、读取会话入口并理解四层规格知识如何配合。
- [导航、上下文与规格分层](developer/navigation-and-context.md)：在不通读仓库的情况下找到权威事实、正确上下文入口和对应的 specs 知识层。 解释 INDEX/导航收据、AGENTS/llms 双入口与 specs 四层的使用顺序。

**更新与恢复**：读者需要选择正确的安装后入口，执行更新并在环境、状态或发行物异常时恢复。
- [更新、运行与故障恢复](developer/update-and-recovery.md)：区分 init/update/工作流入口，执行更新前检查，并按症状定位状态、环境、发行物或扩展源问题。 提供日常更新和常见失败的可恢复操作链。

**验证与知识维护**：读者需要确认索引、地图、上下文和知识资产没有漂移，并知道静态检查不能证明什么。

## Maglev 是什么

Maglev 不是代码生成工具、IDE 或部署平台，而是编码工具的上游输入层与下游验证层：上游整理意图、边界和完成标准，下游检查实现是否仍与这些依据一致。

事实依据：[Maglev 定位与边界](../../internal Reality/positioning.md)。

## 它解决什么问题

AI Coding 提高了执行速度，但也会放大意图、设计、代码和验证之间的漂移。Maglev 用需求收敛、结构化 Spec、明确执行边界和交叉验证，把一次交付从“生成代码”变成“持续对齐并沉淀事实”。

事实依据：[Maglev 定位与边界](../../internal Reality/positioning.md)。

## 它如何参与一次交付

```mermaid
flowchart LR
    intent["意图与需求"]
    design["方案与边界"]
    intent --> design
    implementation["受控实施"]
    design --> implementation
    verification["综合验证"]
    implementation --> verification
    assets["当前事实与资产"]
    verification --> assets
```

| 阶段 | 读者应理解什么 |
|---|---|
| 意图与需求 | 明确目标、范围、成功标准和不能承诺的结果。 |
| 方案与边界 | 将需求形成可执行的 Spec、设计和验证依据。 |
| 受控实施 | 由团队自选的编码工具或受控执行能力完成实现。 |
| 综合验证 | 对照 requirements、spec、code 和 tests 检查漂移与证据。 |
| 当前事实与资产 | 将已经验证的结论沉淀到可维护的 Reality 和知识入口。 |

## 事实与边界

- 当前事实与边界：`internal Reality`
- 正式指南与操作资料：`source operation guides`
- Wiki 按读者任务组织解释、评估和操作路径，不取代当前事实源。
- 边界：
- 不替代代码生成层，也不限定具体 IDE、Agent 或 provider。
- 不负责运维、部署和监控；这些由对应的交付与运维工具承担。
- 页面、配置或静态协议存在，不等于端到端运行效果已经成立。
