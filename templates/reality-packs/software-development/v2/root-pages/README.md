## 落地约束

- 本页固定物化到目标 Reality 根目录的 `README.md`，不物化到 `root-pages/`。
- 范围、静态基线、纳入事实类型和排除项必须有来源锚点；缺证据时保留 `unknown` 或 `blocked`。
- 每个导航入口必须指向可继续深挖的 owner page、模块路径或来源锚点，不能只指向目录名。
- 本页只写目标项目事实；本模板的正向示例只说明表达形状，不能复制为项目事实。

## 模板审阅项

- 入口是否能让读者按问题进入恰当的 owner page，而非堆放全局摘要？
- 范围、静态基线和排除项是否具体可读？
- 模块链接是否指向可深挖页面，而不是技术目录或 claim 标识？
