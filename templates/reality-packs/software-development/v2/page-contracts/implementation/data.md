# 数据模型模板

## 读者问题

模块拥有或使用哪些实体、字段和关系；数据从哪里定义、怎样访问、哪些数据行为没有静态证据？

## 静态来源角色

数据库定义、Schema、实体、ORM/Mapper 和查询代码建立数据事实；需求只说明业务含义，不能单独证明表
或字段存在。

## 模板审阅项

- 字段是否同时区分“存在”“业务含义”“运行时语义未知”？
- 关系是否给出访问锚点，而非靠 ER 想象？
- 数据所有权是否与“仅使用”分开？
